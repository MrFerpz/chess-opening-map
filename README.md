# Opening Map

See your chess openings as an interactive sunburst chart. Enter a Lichess or Chess.com username, and Opening Map draws every line you play as White and as Black.

Live site: [openingmap.com](https://www.openingmap.com)

## Run locally

```sh
npm install
npm run dev
```

## Credits

Game data comes from the [Lichess](https://lichess.org/api) and [Chess.com](https://www.chess.com/news/view/published-data-api) APIs. Opening names come from [lichess-org/chess-openings](https://github.com/lichess-org/chess-openings). Engine analysis uses [Stockfish](https://stockfishchess.org) (GPL-3.0).
